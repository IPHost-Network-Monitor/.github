## What Is IPHost Network Monitor

IPHost Network Monitor is a host-watching helper for a lab or a small office. IPHost Network Monitor host check is the basic question: is this machine answering? IPHost Network Monitor service test asks a narrower question about one service on that machine. You point both at equipment you already look after.

IPHost Network Monitor snmp poll adds numbers from devices that trust this station. IPHost Network Monitor uptime chart turns the checks into a picture of the day. IPHost Network Monitor alert mail carries the bad news to a mailbox you read, which fits a person who also teaches or sits at a service desk. Nothing here is aimed at networks you do not administer.

A useful first day is small. One IPHost Network Monitor host check, one IPHost Network Monitor service test, and one IPHost Network Monitor alert mail. After that, IPHost Network Monitor uptime chart shows whether the setup was calm. Add IPHost Network Monitor snmp poll when a switch or server already allows your station to poll it.
